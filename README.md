## 🔥 Featured Projects

### 🪄 MagicDrop.io
> *Zero-setup peer-to-peer file & message transfer — right in your browser.*

A browser-based P2P transfer tool built with **WebRTC via PeerJS**. No servers. No sign-ups. Just share a link and drop files. Deployed as a **single HTML file** on GitHub Pages under the **KAI Laboratories** brand, complete with a cyberpunk aesthetic — KAI green, scanline effects, Orbitron typography, and an animated teleportation logo.

`WebRTC` `PeerJS` `Vanilla JS` `GitHub Pages` `Cyberpunk UI`

---

### 🌞 Project Helios
> *AI-powered content detection with a cyberpunk soul.*

A web app that detects AI-generated content using the **Claude API**. Features an animated SVG sun logo, dark-mode first UI, and a user-supplied API key panel to bypass CORS on GitHub Pages.

`Claude API` `HTML/CSS/JS` `GitHub Pages` `AI Detection`

---

### 🦯 Smart Blind Stick
> *Assistive technology for the visually impaired.*

An Arduino-based smart navigation device using an **HC-SR04 ultrasonic sensor** and **HC-05 Bluetooth module** to detect obstacles and relay audio alerts directly to a paired Android phone via a custom **MIT App Inventor** companion app.

`Arduino` `HC-SR04` `HC-05 Bluetooth` `MIT App Inventor` `Embedded C++`
